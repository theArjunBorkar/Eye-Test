Eye Test

A rating system built from structured match data, computer-vision-derived video features, machine learning, and exploratory factor analysis — scoped to Ajax players across the matches recorded so far.

How the rating works

Each player-match row starts from hand-recorded FM26 stats (passing, attacking, defending, discipline), cleaned to remove unused-substitute appearances and flag small-sample cameos. From there, per-90 rates and composite features (goal contributions, defensive actions, a discipline score) are engineered. Match-level video features (how many players a detection model picked up per frame, how often the ball was visible) are joined in per match, and Random Forest and XGBoost models are trained on stats alone and on stats plus video, then checked two ways, including by holding out entire matches. That second check is what showed the apparent video gain doesn't transfer to a match the model hasn't seen. Exploratory factor analysis separately looks for underlying performance dimensions across the stat set without assuming what they are in advance.

This is a small, growing dataset — 5 matches so far — so every result on this page is shown alongside how much it should currently be trusted, not just the number itself.

Limitations

Documented plainly, not buried — the state of this project after 5 matches.

  • Small sample. 5 matches, 78 usable player-match rows. Every statistical result on this page (model metrics, factor structure) should be read as "pipeline verified," not "validated finding," until meaningfully more matches are recorded.
  • FM26's own rating, not a real-world expert rating. The prediction target throughout is FM26's in-game match rating — a reference signal, not a professional scout or analyst's judgement.
  • Video features are match-level, not per-player. Basic YOLO detection has no way to know which player is which without jersey-number recognition, which was scoped out. No individual player's video-derived activity is measured — only whole-match detection counts.
  • Tracking-based video features are unreliable for this footage. FM26 highlight clips are a montage of short scenes; a simple centroid tracker with no scene-cut detection or camera-motion compensation can't distinguish a cut from someone leaving. Distance/sprint numbers reflect that, not player effort.
  • Possible train/test leakage in model evaluation. The same player appears across matches; K-fold cross-validation (not GroupKFold) may let a player's identity leak between folds rather than the model purely learning from performance features.
  • Highlight clips, not full match footage. Off-ball actions that don't make the highlight reel aren't captured by either the stats (hand-recorded from what's shown) or the video pipeline.
